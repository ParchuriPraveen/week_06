CSS Fundamentals

See clearly where CSS is written and how it is used

1. INLINE CSS

This paragraph uses Inline CSS.

<p style="color: red;">
  Hello World
</p>

📍 WHERE?

CSS is written directly inside the HTML element using the style attribute.

Example:

style="color:red;"

2. INTERNAL CSS

This paragraph uses Internal CSS.

<style>
  p {
    color: red;
  }
</style>

📍 WHERE?

CSS is written inside the <style> tag in the <head> section.

Example:

p { color: red; }

3. EXTERNAL CSS

This paragraph uses External CSS.

HTML FILE

<link rel="stylesheet"
href="style.css">

CSS FILE
style.css

📍 WHERE?

CSS is written in a separate .css file and connected to the HTML file.

Example:

p { color: red; }

🔍 MAIN DIFFERENCE

CSS Type Where CSS is Written? Example Used For
Inline CSS Inside HTML element style="color:red;" One element
Internal CSS Inside <style> p { color:red; } One webpage
External CSS Separate .css file style.css Multiple webpages
